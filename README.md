# Haos — fichiers du launcher

Ce dépôt contient la liste des fichiers du serveur Minecraft **Haos** (`manifest.json`) et nos propres fichiers (`files/`).
Il est lu automatiquement par le **Haos Launcher**.

**Joueurs :** téléchargez le launcher dans [Releases](https://github.com/N8lyuG/haos-launcher/releases/latest), lancez-le puis cliquez sur **JOUER**.
Il faut le launcher Minecraft officiel et un compte Minecraft Java.

Les mods tiers ne sont pas hébergés ici : le launcher les télécharge depuis Modrinth ou CurseForge.
`files/mods/apocalypsenow-…_HAOS-V2.jar` est une version modifiée d'Apocalypse Now (JPZamps), sous licence Academic Free License v3.0.
